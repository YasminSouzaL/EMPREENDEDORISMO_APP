# Enigma

- O Portal Enigma administrativo fica em `frontend/admin/`. O site do estudante fica em `frontend/student/`. Ambos usam a API em `backend/`.
- Use inglês para identificadores e português para comentários e textos da interface.
- Consulte [Frontend](knowledges/frontend.md) para arquitetura, tema e build.
- Consulte [Integração](knowledges/integracao.md) para os contratos existentes e os limites do protótipo.
